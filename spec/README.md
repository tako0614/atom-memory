# Atom Memory — 歴史資料 v1.0

2026-09-10。会話中のv0.1、v0.2、v0.3とCell撤去の提案を統合した、当時の設計案です。現在の公開契約は `src/client/types.ts`、検索設計は `docs/ranking.md` を参照してください。

## 中心

一つのAtom集合、read/writeの意味操作、通常エージェントとWriterで共通のハーネス。
所属も独立したAtomとし、親の巨大配列や全祖先の同期再生成を必須にしません。
ViewとWorkspaceは内部の計算・実行状態であり、別種のメモリではありません。

## ファイル

- `ARCHITECTURE.md`：最終仕様、更新/検索/整合性/スケールの契約、受入条件、開発計画。
- `architecture.mmd`：編集用Mermaidソース。画像へレンダリングしていません。

## 状態

TypeScriptの型検査のみ実施。最終仕様のCore、実LLM、永続ストレージ、分散通信、アクセス制御の実装は含みません。ARCHITECTURE.mdの受入条件は今後実装する試験です。過去版の小モデル試験を、この最終仕様の実装済み結果とは扱いません。

## 重要な境界

固定版へのincludeのみDAGを保証し、動的所属を含む関係全体は有限に探索する一般グラフです。親Atomの版を固定しても、外付けの所属全体を固定したことにはならず、所属の読取状態も記録します。論理集合が一つであることは、全世界の同時点snapshotや単一トランザクションを意味しません。必要な整合性・原子性をバックエンドが提供できない場合は、黙って弱めずエラーにします。

資料中の外部参照は設計の先行例です。性能や新規性の実証は別途必要です。

旧型契約・例・型検査記録はgit履歴に保存しています。現行パッケージに重複した公開契約として同梱しません。
