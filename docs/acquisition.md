# 活性に基づく探索の研究

**試作と比較を完了しました。今回の方式は既定へ採用せず、npmは0.9.0を維持します。**

0.10候補の課題は、取得したAtomの順位だけでなく、次に取得する関係も同じ活性から選ぶことです。本文・利用・関係の式、`read / search / inspect / write`、必須条件を伴う本文選択は維持します。

ここでの優先度は探索順の推定です。未取得ページの有益さの上界、情報の真偽、Atomの恒久的な重要度ではありません。

## 一件ずつ読むだけでは公平にならない

多数の子へ活性を伝える入口は、それぞれの子より高い活性を持ち得ます。毎回最大の活性を選ぶと、一ページごとに選び直しても同じ入口を読み続けます。

試作では、ある一巡の開始時にある「Atomの観測版・方向」へ、それぞれ最大一回の取得を割り当てます。その中の順序を活性で決め、新しく発見した探索先は次の一巡へ加えます。この配分だけを使い、活性順にしない対照も用意します。配分の効果を活性の効果と呼ばないためです。

正引きのslot一件、または逆引きのposting一件が処理単位です。保存アダプターが本文と全slotを読み込む費用も測ります。一件だけ処理したことは、物理I/Oが一件分になる保証ではありません。

## 計算と探索を交互に行う

初期候補は本文・ベクトルの索引から取得します。新しいAtomにも、その本文と固定したコンテキストから直接活性を与えます。現在のグラフを評価し、未取得の関係を一件開き、構造が変わった場合に活性を補正します。

辺が増えると伝播先の正規化も変わるため、新しい辺の分だけ加える方式にはしません。最終結果は、同じ取得済みグラフを最初から解いた結果と数値誤差の範囲内で一致させます。その保証は、初期索引や未取得の関係を含む全記憶の検索完全性とは別です。

遠回りから先に見つけたAtomへ近道が見つかった場合、既知の最短距離を修正し、深さ上限の内側に入った探索先を再び有効にします。同じAtomや辺を複製しません。本文が表示予算へ入らないAtomも、経由点には使えます。

## 何を測るか

同じコンテキスト、固定4次元ベクトル、Atomの版、利用状態、予算を、次の六方式へ与えます。Writerや回答モデルは変更しません。

| 方式                     | 調べること                     |
| ------------------------ | ------------------------------ |
| 初期候補のみ             | 関係探索なしの基準             |
| v0.9のFIFO取得           | 現行の取得処理との差           |
| 活性順だけ               | 一つの入口が予算を独占する場合 |
| 一巡の配分だけ           | 探索先を交代することの効果     |
| 一巡の配分＋同じ暫定評価 | 計算費用をそろえた登録順の対照 |
| 一巡の配分と活性順       | 活性に基づく順序の追加効果     |

取得した根拠、実際に表示した根拠、必須条件の欠落、bytes、候補件数、暫定・最終評価の計算、本文選択の計算、実時間を分けます。準備と索引作成は取得とは別に測り、全方式へ同じ初期状態を複製します。数値検証用の密行列計算は測定後に行います。

研究コードでは、同期transactionの間、fixtureの利用状態を変更せず、明示した同一時刻で評価します。全体の時計を止めないため、deadlineは実時間で動きます。この条件は、非同期更新を許す製品のsnapshot実装を完成させたことにはなりません。

## 採用条件

活性順を加えた方式が配分だけの方式を上回り、必須条件・権限・版・深さ・数値評価に回帰がなく、途中の再評価と検証費用を含めても利益が残ることを求めます。直接候補だけで足りる小さいケースの追加費用も含みます。

この条件を満たさなければ、公開版の取得方式はv0.9を維持します。新しい公開オプションや記憶型を追加して、採否の判断を利用者へ移すことはしません。

## 今回の結果

15構造・10予算条件・6方式・Memory/SQLite・各3回、合計5,400回を測定しました。十分な予算では、関係を探索する方式は全て15ケースの根拠を返しました。活性順を使う方式の評価計算は、配分だけの方式の約4.3倍でした。

各アダプターの150予算条件では、活性順を加えて表示根拠が増えた条件は、安い配分だけの対照に対して0件、減った条件は10件でした。同じ暫定評価を行う登録順の対照に対しては、改善も悪化も0件です。FIFOを上回る条件が一件ありましたが、配分だけでも取得できました。

必須条件の欠落、staleな生成物、認可、消去、深さの修正、数値誤差、ledgerの回帰を検査しました。この具体的な試作には、既定を変更するだけの追加効果がありません。一般的な活性探索の可能性まで否定する結論ではありません。

測定範囲、時間、数値誤差、修正したfixture、再現手順は[結果と採否](https://github.com/tako0614/atom-memory/blob/main/research/v010/REPORT.md)に記録しています。固定ベクトルの構造試験であり、実LLMの回答品質や全履歴の網羅性の評価ではありません。

再現コードと詳細な契約は、[research/v010](https://github.com/tako0614/atom-memory/tree/main/research/v010)に置きます。
