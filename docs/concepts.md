# Atom と関係

原資料・抽出・集合・所属・主張・要約を、同じ `AtomRevision` で表します。`schema` はデータの解釈名です。コード実行や権限付与の命令にはなりません。

## 同一性と版

`atomId` は論理的な同一性、`revisionId` は不変版です。更新は `expectedHead` と一致する場合だけ、新しい版として受理します。同じ版からの競合を時刻で上書きしません。

```text
B:1 ── 改訂 ──> B:2
 ↑                ↑
pinned(B:1)     logical(B) を新しい snapshot で解決
```

別人の同じ文や別の出来事は、別の Atom として残せます。類似度だけで同一化しません。

## 所属を独立させる

```text
P ── membership:PB ──> B
Q ── membership:QB ──> B
```

`PB` と `QB` も Atom です。P へ D を追加する操作は新しい membership の作成です。P や祖先の版は変わりません。PB を `retired` にすると P からの所属だけが解除され、B と QB は残ります。

順序が必要なら member slot の `orderKey` を使います。同じ要素の複数の出現を保存できます。表示順は因果順の保証ではありません。

## include と refer

| 参照      | 対象             | 意味                                         |
| --------- | ---------------- | -------------------------------------------- |
| `include` | pinned のみ      | 不変版の構成。受理する有限バッチで循環を拒否 |
| `refer`   | pinned / logical | 言及・関連。本文を暗黙に無限展開しない       |

動的所属の一般グラフには循環があり得ます。読取は訪問済み版と hop 予算で止まり、関係 Atom の参照は出力に残ります。

**集合 P の版を固定しても、外付けの所属集合は固定されません。** 所属を再現するには、その検索を行った snapshot receipt を指定します。固定 include の展開へ動的な逆引きを混ぜません。

## 出典と派生物

原文の座標は原資料の Atom ID・版 ID・UTF-8 半開区間・SHA-256 digest です。文字の途中を指す範囲を拒否します。保存した原文の bytes が座標の基準です。

`inputReceiptId` はホストが実際に読んだ入力の記録、`origins` は生成物が引用する原資料です。引用しなかった入力も計算依存から消しません。内容の意味が保たれたかは別の評価です。

派生物の再利用時には入力版と検索範囲を検証します。所属の新規挿入や入力改訂で依存が変わった場合は、その派生物を現在の根拠として返さず `derivedState: pending` を返します。古い snapshot では古い版の結果を読めます。
