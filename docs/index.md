## メモから、回答に使える資料へ

例えば、サポート担当のエージェントに「招待リンクの有効期限」を覚えさせます。運用メモを `write` で保存し、招待手順の説明と関係をつなぎます。「リンクはいつ切れる？」と聞かれたとき、`read` が関連するメモを選び、モデルへ渡す資料を組み立てます。

有効期限が変わったら、そのメモの参照を使って `edit` で訂正します。新しい質問には更新後の記憶を使い、以前の回答の根拠を調べるときは `inspect` で当時の版を確認できます。

```sh
npm install atom-memory
```

Node.js 22.13 以降で使えます。まずはプロセス内の保存で動かし、継続して使うデータは SQLite に保存できます。
