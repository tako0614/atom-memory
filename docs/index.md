<div class="memory-introduction">

## 小さなメモから、頼れる文脈へ。

Atom Memory は、エージェントのための TypeScript メモリライブラリです。ユーザーの好み、運用ルール、作業で分かったことを保存し、今の問いに必要な資料をモデルへ渡します。

</div>
<div class="memory-features">
<div>
<h3><span class="memory-feature-number">01</span> そのまま覚える</h3>
<p>まずは文章を <code>write</code> するだけ。メモ同士の関係も、後から参照でつなげられます。</p>
<a href="/api#write">保存する →</a>
</div>
<div>
<h3><span class="memory-feature-number">02</span> 今に合わせて思い出す</h3>
<p>質問や作業の文脈を <code>read</code> へ。予算に収まる資料を選び、モデルに渡す記憶を組み立てます。</p>
<a href="/runtime">エージェントにつなぐ →</a>
</div>
<div>
<h3><span class="memory-feature-number">03</span> 変わったら、直す</h3>
<p>好みやルールが変わっても大丈夫。内容を改訂し、以前の版や出典も参照できます。</p>
<a href="/examples#change-preference">訂正してみる →</a>
</div>
</div>
