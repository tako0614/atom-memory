# はじめる

Atom Memory にメモを保存し、質問に必要な資料を取り出してみます。モデルや埋め込みを接続する前に、次のコードだけで保存と検索を試せます。

```sh
npm install atom-memory
```

Node.js 22.13 以降の ESM プロジェクトで使います。アプリからは、[一度設定したクライアント](/setup)を `memory` として受け取ります。

## 保存して、取り出す

<<< ../examples/basic.mjs

`memory.mjs` は [ホストの設定](/setup)にある初期化ファイルです。この二つのファイルを同じフォルダーに置き、`node basic.mjs` で実行できます。

| この例の操作             | 得られるもの                                                 |
| ------------------------ | ------------------------------------------------------------ |
| `write('…')`             | 保存したメモと、その参照                                     |
| `search('招待リンク')`   | 関連するメモの一覧。例では「有効期限は24時間です」という本文 |
| `read({ context: '…' })` | 今回の問いに使う本文・参照・出典をまとめた記憶領域           |

`search` は候補を自分で調べたいときに使います。`read` はモデルへ渡す資料を受け取る操作です。上の `recalled.text` を参考資料として渡し、モデルが回答を作ります。

## エージェントに使う

[MemoryHarness](/runtime)にクライアントとモデルを渡すと、モデル呼出しの前に `read` を自動で実行します。次のステップでは、そのときの作業に合わせて記憶を選び直します。

## 必要になったら進む

- メモの根拠を確認したい → [`inspect`](/api#inspect)
- 保存した内容を訂正したい → [`edit`](/api#edit)
- メモ同士をつなぎたい → [Atom と関係](/concepts)
- 終了後もデータを残したい → [SQLite](/adapters#sqlite-に保存する)

すべての操作は同じ `memory` を使います。詳細なオプションは [API リファレンス](/api)で確認できます。
