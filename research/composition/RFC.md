# Atom Memory：合成可能な連想評価を核にする研究RFC

状態：提案。既存ライブラリへの実装指示・採用決定ではない。

確認基準：v0.5.0 / `43ef7182467b348253f6279305a41a264d6908c9`。
作成日：2026-09-13。

この文書は、同日ユーザーが提示したRFCの設計契約と採否条件を整理した要点版。ユーザー報告の数値試験と、作業中だったJS試作の実測は[研究記録](README.md)で区別する。

## 設計の一文

内容と関係を保存し、文脈に応じて必要な解像度まで読む。計算のために畳み方を変えても、定義された記憶の働きを変えない。

Atomは本文と役割付き参照を持つ情報。親は関係上の役割であり、Cellや用途別の永続メモリ型ではない。`read/search/inspect/write/edit` の責務分離を維持する。関数数を減らすこと自体を目的にしない。

## 三つの法則

1. 内容・関係・出典・版が正本で、検索結果は派生物。読み出しは文脈に従うが、意味上の関係を勝手に追加しない。利用傾向による数値キャッシュの配置と、用途に合わせた意味の再編を区別する。
2. 共有Atomは同じ一つの変数。PとQがBを共有しても、独立した二つの内部変数にしない。Atom IDの同一性と自然言語の同一性は別。同文の発言や同じ出典の別主張を自動統合しない。
3. 折り畳みは計算計画で、新しい知識ではない。固定した入力・版・認可・役割重み・参照グラフで、全展開と消去・復元を一致させる。要約、分割、関係追加がすべて同値とはしない。

## 責務とアーキテクチャ

```text
Agent / アプリ：内容理解・構造化・モデル実行・運用
                        ↓
          read / search / inspect / write / edit
                        ↓
               版付きのAtomグラフ
                        ↓
           本文索引から今回の検索信号を得る
                        ↓
        関係評価・局所計算の再利用・必要な詳細化
                        ↓
               本文・関係・出典のパッキング
```

本文の直接埋め込み、役割、出典、観測版、認可、公開操作、ハーネス非依存を維持する。説明Atomは自身の本文で候補になれるが、内部を代表する完全なベクトルとは仮定しない。子の本文を暗黙に連結せず、計算行列を知識Atomとして公開しない。

計算境界は所有権・意味分類・保存シャード・公開spaceと一致させない。意味上のまとまりは計画の候補であり、すべての親にキャッシュを作る仕様にしない。境界が密で不利なら通常評価へ戻る。

モデル実行、人格、Writer、入力取得、ジョブ、費用管理、履歴採用、時間方針、read中のLLMによる意味修正、大規模な独自学習はCoreへ追加しない。

## 消去で落としてはいけないもの

- 内部本文へ直接一致したseed。外部から流入する値だけの表では不足する。
- 正規化に必要な内部mass。境界だけを合計1へ正規化しない。
- 一つの共有変数と外部接続。二つの計算表を単純加算しない。
- 最終的に返す本文、出典、必須条件。境界の値が分かることと、内部top-kや出力が確定することを区別する。

候補発見の不確実性、未取得のグラフ範囲、数値誤差、意味の正しさは別物。省略した辺を除いて再正規化した小グラフの解を、全グラフの厳密解と呼ばない。

## 参照する数値契約

非負辺を始点で正規化した列方向遷移をTとし、出辺のない列は0とする。sは非負・合計1、`0 <= alpha < 1`。

```text
A = I - alpha*T
y = solve(A, s)
r = y / sum(y)
```

これは現行のdangling再分配付きPPRの収束先に一致する。既定32反復の中間値とのビット単位の同一性ではない。

```text
S   = A_BB - A_BI*solve(A_II, A_IB)
y_B = solve(S, s_B - A_BI*solve(A_II, s_I))
y_I = solve(A_II, s_I - A_IB*y_B)
```

逆行列の明示的構築を避け、因子分解や局所作用を検討する。Schur補は密になり得る。

文脈と構造の変更は、同じ残差補正として表せる。

```text
residual = s_new - A_new*y_old
correction = solve(A_new, residual)
y_new = y_old + correction
```

過去の関連度を意味上の加点として維持しない。十分に計算すればcold評価と一致させる。影響が広がる場合もあり、局所変更の一定費用は保証しない。

固定Tに対し、残差eから `||y - y_hat||_1 <= ||e||_1 / (1-alpha)` が得られる。正規化後の値・順位に利用するにはその変換と候補全体の条件が必要。全資料の検索完全性や回答の真偽の境界ではない。

## 未完成の研究対象

内部候補が上位候補や必須条件の選択を変え得るかを評価し、変化の可能性と実測・推定の展開費用から次の一部分を選ぶ。内部を開いて補正し、予算内で繰り返す。未確定ならその範囲を隠さず有限で返す。

研究の本体は、出典と必須条件の閉包を含む出力費用、未評価部分の上界、展開スケジューラーの規則と保証条件。折り畳みや残差だけを新規性の根拠にしない。数値変数の復元を選ぶ試作だけでは、この出力まで含む問題設定を解いたことにならない。

## 段階と採否条件

| 段階          | 比較                                                                                                             |
| ------------- | ---------------------------------------------------------------------------------------------------------------- |
| A：評価契約   | 完全既知の認可済みグラフ・固定seed・固定重みで通常評価と消去・復元を比較。dangling、循環、内部seed、共有点を含む |
| B：合成と更新 | 互いに素な内部の消去順、共有境界、文脈・本文・関係・認可変更、warmを捨てたcold評価を比較                         |
| C：詳細化     | 同じ入力・スコア定義・予算で、フラットPPR、local-push、ブロック前処理と比較。意味構造は評価質問を見ずに作る      |

指標は、参照計算との差、必要な証拠集合、条件欠落、候補発見の取り逃し、準備時間、キャッシュ容量、更新費用、cold/warm遅延。高速化と意味品質改善を分ける。

境界が大きい、更新が多く再利用できない、候補発見が支配的、warmが高い、単純なlocal-pushに勝てない場合は不採用を許す。意味の正本を変える移行を前提にしない。

## 先行と実験結果の位置付け

埋め込みとPPR、再帰的集約、ブロック消去と動的更新、残差push、構造表現への頑健性、境界作用の合成には先行がある。対象モデルや保証条件は同じとは限らない。世界初、方式の完成、論文採択を主張しない。

ユーザー提示RFCは `algebra_lab.py` と `results.json` による120グラフの数値試験を報告している。最大差約1.63e-13、内部seed省略の反例、starの消去で境界が密になる反例を含む。その報告は既知の数学の確認であり、速度・メモリ削減・実LLM・近似索引・非同期更新・物理分散の検証ではない。元ファイルはこのディレクトリには含まない。
